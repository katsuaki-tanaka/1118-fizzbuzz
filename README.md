# FizzBuzz Web Viewer (1〜50)

1から50までの数値を判定し、結果を視覚的にわかりやすく一覧表示する Web アプリケーションです。
HTML / CSS / JavaScript を単一の `index.html` にまとめており、外部ライブラリやビルドツール不要でそのまま動作します。

---

## 🌟 特徴

- **カード/グリッド表示**: 各数値をカード形式でレスポンシブにレイアウト。
- **視覚的な色分け**:
  - **FizzBuzz**（15の倍数）: パープル/ピンクグラデーション
  - **Fizz**（3の倍数）: スカイブルー
  - **Buzz**（5の倍数）: アンバー/オレンジ
  - **通常数値**: ニュートラルグレー
- **フィルタ & 統計バッジ**: 上部のチップをクリックすることで、「すべて」「FizzBuzz」「Fizz」「Buzz」「数値のみ」で瞬時に絞り込みが可能です（各件数もリアルタイム表示）。
- **ゼロ依存 & 単一ファイル**: ブラウザで開くだけで即座に動作します。

---

## 📐 FizzBuzz 判定ルール

| 条件 | 表示 | 例 |
| :--- | :--- | :--- |
| **15 の倍数**（3 と 5 の公倍数） | `FizzBuzz` | 15, 30, 45 |
| **3 の倍数** | `Fizz` | 3, 6, 9, 12 ... |
| **5 の倍数** | `Buzz` | 5, 10, 20, 25 ... |
| **その他の数値** | その数値 | 1, 2, 4, 7 ... |

---

## 🚀 使い方 / 閲覧方法

特別なサーバー環境やインストール作業は不要です。

1. 本リポジトリをクローンまたはダウンロードします。
2. `index.html` を任意の Web ブラウザ（Chrome、Edge、Safari、Firefox など）で開くだけで閲覧できます。

```bash
# クローン例
git clone git@github.com:katsuaki-tanaka/1118-fizzbuzz.git
cd 1118-fizzbuzz

# ブラウザで開く（Windows の場合）
start index.html
```
